# 🛒 Amazon Clone

> A frontend e-commerce website inspired by Amazon, built from scratch using **HTML5 & CSS3**.

---

## ✨ About the Project

This project is a **static Amazon-inspired e-commerce homepage** created to practice and demonstrate frontend development fundamentals.

The project focuses on recreating the structure and visual experience of a modern e-commerce website using HTML, CSS, images, layouts, and different product sections.

---

## 🚀 Features

- 🏠 Amazon-inspired homepage
- 🔍 Navigation bar and search interface
- 🖼️ Hero section with promotional banner
- 🛍️ Product categories and shopping sections
- 🔥 Deals and trending product sections
- 📦 Multiple product cards and collections
- 🎨 Clean and organized e-commerce style UI
- 📱 Structured layout for a better browsing experience

---

## 🛠️ Tech Stack

| Technology | Used For |
|---|---|
| 🟠 **HTML5** | Page structure and content |
| 🔵 **CSS3** | Styling, layouts and visual design |
